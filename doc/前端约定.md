# audit-platform 前端开发约定

> 事实源：后端接口见 [`../doc/API.md`](../doc/API.md)；设计语言见设计文档 8.1。

## 技术栈

Vue 3.5（`<script setup lang="ts">`）+ Vite 7 + TypeScript 5.9（严格模式，`noUncheckedIndexedAccess: true`）
+ Element Plus 2.13（中文 locale）+ Pinia 3 + vue-router 4。

**不要引入新的 npm 依赖**（图表用 SVG 手绘）。

## 页面骨架模板

```vue
<script setup lang="ts">
import { onMounted, watch } from 'vue'
import { ElMessage } from 'element-plus'
import PageHeader from '@/components/PageHeader.vue'
import StatusTag from '@/components/StatusTag.vue'
import { useListQuery, useTableLoader } from '@/composables/useListQuery'
import { get } from '@/api/http'
import type { XxxItem } from '@/api/types'

const query = useListQuery({
  defaultSort: { field: 'created_at', direction: 'desc' },
  sortableFields: ['created_at', 'name'],
  filterKeys: ['status'],
})
const table = useTableLoader<XxxItem>(async (params) => {
  const payload = await get<{ items: XxxItem[]; total: number }>('/api/admin/v1/xxx', params)
  return { items: payload.items ?? [], total: payload.total ?? 0 }
})

onMounted(() => void table.load(query.requestParams.value))
watch(() => query.requestParams.value, (params) => void table.load(params), { deep: true })
</script>

<template>
  <div class="ap-page">
    <PageHeader title="标题" desc="一句话说明">
      <template #actions>
        <el-button type="primary">新建</el-button>
      </template>
    </PageHeader>

    <div class="ap-card">
      <div class="ap-card__body ap-card__body--flush">
        <el-table :data="table.items.value" v-loading="table.loading.value" class="ap-table">
          <el-table-column prop="id" label="ID" width="120" />
        </el-table>
      </div>
    </div>
  </div>
</template>
```

## 硬性规则

1. 权限不足的按钮**置灰 + tooltip 说明**，不要直接隐藏。
2. 危险操作（删除、永久删除、停用）必须二次确认；永久删除要求输入对象全名完全匹配。
3. 错误统一用 `ElMessage.error(err instanceof ApiError ? err.message : '操作失败')`。
4. 空状态用 `EmptyState`；列表加载中用 `v-loading`；行内错误用 `el-alert`（不覆盖整页）。
5. 中文文案；**不写解释性说明文案**（只写状态与操作文案）。
6. 表格里数字与编码用 `.ap-mono` 类；数值列右对齐（`align="right"`）；时间列固定宽度 160px。
7. 分页：`el-pagination` 放右下，总数放左下，每页条数 20/50/100。
8. 深分页（offset > 1000）提示「请增加筛选条件」。
9. **每个页面都要能通过 `pnpm type-check`**：数组下标访问要判空（`arr[0]?.id`）。
